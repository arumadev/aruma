# ADR-010: الافتراضيات الآمنة

- الحالة: معتمد
- التاريخ: 2026-10-18
- المرحلة: 1
- المراجع: [docs/research/auth-and-secrets.md](../research/auth-and-secrets.md)، [docs/security/threat-model.md](../security/threat-model.md)

## السياق

نسخة Aruma يشغّلها غالبًا شخص واحد، وقد تكون مكشوفة على الإنترنت من أول دقيقة. ما لا يكون آمنًا افتراضيًا لن يكون آمنًا عند أغلب المشغّلين. لذلك نتعامل مع هذه القائمة كشرط إصدار، لا كتوصيات.

## القرار

### 1. القائمة شرط إصدار

لا يُصدَر إصدار إلا وكل بند هنا مطبَّق، ولكل بند اختبار سلبي في CI يحاول كسره.

| # | الافتراضي | الاختبار السلبي |
|---|---|---|
| S-1 | لا حساب ولا كلمة مرور افتراضيان. أول حساب يُنشأ برمز إعداد لمرة واحدة يُطبع في السجل | AC-4: الإعداد بلا رمز، أو برمز خاطئ، أو للمرة الثانية: مرفوض |
| S-2 | التسجيل مغلق افتراضيًا | AC-20 |
| S-3 | `Bearer owner` وأي JWT بـ `alg: none` مرفوضان دائمًا، ويُسجَّل الرصد | AC-28 |
| S-4 | كل مسار في واجهة اللوحة يتطلب جلسة، إلا الإعداد والدخول والتسجيل وحالة الإقلاع | اختبار يمر على كل المسارات المسجّلة دون جلسة ويتوقع 401 |
| S-5 | كل طلب يغيّر شيئًا بـ cookie يتطلب رمز CSRF مربوطًا بالجلسة في `X-Aruma-CSRF`، فوق فحص `http.CrossOriginProtection` | طلب بلا رمز، أو برمز جلسة أخرى، أو من أصل آخر: مرفوض |
| S-6 | حدود معدل للدخول لكل IP ولكل بريد، وتأخير متصاعد بعد الإخفاق | المحاولة السادسة خلال النافذة: 429 |
| S-7 | رسالة دخول واحدة للحساب المجهول وكلمة المرور الخاطئة والحساب الموقوف، وتحقق وهمي يوحّد التوقيت | المقارنة بين الحالات الثلاث: الرد نفسه |
| S-8 | CORS مغلق: لا ترويسة `Access-Control-Allow-Origin` في أي رد | طلب بأصل آخر: لا ترويسة |
| S-9 | ترويسات أمان على اللوحة: CSP دون `unsafe-inline` للسكربتات، و`frame-ancestors 'none'`، و`nosniff`، و`Referrer-Policy`، وHSTS على https | فحص الترويسات |
| S-10 | مفتاح API لا يمنح أي صلاحية إدارية | كل نقطة إدارية بمفتاح API وحده: 401 |
| S-11 | ما لا يملكه المستدعي يُرد عليه بـ `NOT_FOUND`، لا `PERMISSION_DENIED` | AC-19 واختبارات العزل |
| S-12 | `/metrics` ليس على المدخل العام | طلب `/metrics` على المدخل العام: 404 |
| S-13 | الخادم لا ينفّذ DDL، ويرفض الإقلاع على مخطط قديم | AC-2 |
| S-14 | حد لحجم الجسم (1 MiB)، ومهلات قراءة وخمول | جسم أكبر: 413 |
| S-15 | لا أسرار في السجلات ولا في القاعدة: لا مفتاح خاص، ولا رمز خام، ولا كلمة مرور | X-7: تفريغ القاعدة والسجلات بعد سيناريو كامل لا يحوي أيًّا منها |

### 2. معالجة الأسرار

| السر | كيف يُعالج |
|---|---|
| كلمة مرور صاحب المشروع | argon2id بالقيم `m=19456 KiB, t=2, p=1` (OWASP)، وملح 16 بايت، ومفتاح 32 بايت، بصيغة PHC. بحد أقصى 4 عمليات متزامنة. يعاد التجزيء عند الدخول إن تغيّرت القيم. الطول من 8 إلى 1024 بايت، دون اقتطاع |
| رمز الجلسة، ورمز CLI، ورمز CSRF، ورمز وصول حساب الخدمة | 256 بت عشوائية. يُخزَّن `HMAC-SHA256` منها فقط، بمفتاح مشتق من المفتاح الرئيسي |
| المفتاح الخاص لحساب الخدمة | يُولَّد ويُعاد للمطوّر مرة واحدة، ولا يُخزَّن أبدًا. يُحفظ المفتاح العام فقط |
| أسرار المرحلة 2 (مفاتيح الختم، وSMTP) | تشفير مغلّف: AES-256-GCM بمفتاح بيانات لكل سجل، مغلّف بمفتاح تشفير مُرقَّم الإصدار، والسجل مربوط بموضعه |
| المفتاح الرئيسي | 32 بايت في الإعداد. منه تُشتق مفاتيح كل غرض عبر HKDF-SHA256 |
| مفتاح API | ليس سرًا، ويُخزَّن كما هو |

### 3. الجلسات

- cookie `__Host-aruma_session` مع `Secure; HttpOnly; Path=/; SameSite=Lax`.
  - على http غير محلي يُستعمل الاسم دون البادئة ودون `Secure`، ويُحذّر السجل عند الإقلاع.
- خمول 30 دقيقة، ومطلق 8 ساعات. وكلاهما يُفرض في الخادم.
- جلسة جديدة عند كل دخول. وتغيير كلمة المرور يبطل كل الجلسات الأخرى.

### 4. نموذج التهديد

- يعيش في [docs/security/threat-model.md](../security/threat-model.md)، ويُحدَّث في كل مرحلة.
- قبل إغلاق كل مرحلة: مراجعة مستقلة لـ `authn` و`admin/` بجلسة لم تكتب الكود.

### 5. سلسلة التوريد

SBOM وتوقيع الإصدارات وصور Docker تؤجَّل إلى ما قبل الإطلاق العلني (U-21)، لا في هذه المرحلة.

## البدائل المرفوضة

- **حساب مدير افتراضي بكلمة مرور تُغيَّر لاحقًا:** أغلب النسخ المخترقة في منتجات مشابهة سقطت من هنا.
- **bcrypt:** يقتطع كلمة المرور عند 72 بايت، وargon2id هو توصية OWASP الأولى.
- **تخزين الرموز كما هي:** تفريغ واحد للقاعدة يمنح كل الجلسات.
- **الاكتفاء بـ `SameSite` لمنع CSRF:** OWASP يعدّه دفاعًا إضافيًا فقط.

## العواقب

- أي ميزة جديدة تضيف بنودها إلى الجدول مع اختبارها السلبي.
- المشغّل لا يستطيع الدخول قبل قراءة السجل مرة واحدة. هذا مقصود.
